# The Chronicles of Anandi Raghavi

Prototype medieval-fantasy portfolio built with React + Vite.

## Run

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Notes

- The prototype intentionally uses CSS artwork so it works immediately without Blender or external assets.
- Replace the CSS portal/forest with generated artwork later under `public/assets/landing/`.
- Resume content is based on the uploaded 2026 resume.
